# Telecom Revenue and Customer Churn Analysis
## Project Overview 
Developed an end-to-end analytics solution to analyze revenue performance, understand customer chrun behavior, map revenue loss, and identify high-value customer segments to generate actionable business insights.This project showcases how raw telecom operational data is transformed into structured database layers and visualized through an interactive dashboard.
---
## Business Problem & Objectives
In the telecom industry, retaining high-value subscribers and maintaining a strong Average Revenue Per User (ARPU) is critical.
